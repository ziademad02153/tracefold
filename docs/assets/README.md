# README artwork

The banner, product workflow and platform architecture are original SVG documentation assets using Tracefold's application identity: dark green, lime and neutral surfaces. Their editable source is scripts/render_readme_assets.py. SVGs contain no scripts, external resources or raster dependencies.

The architecture illustrates the full product scope. It is not a runtime support claim. The root README states the implementation boundary.

Technology logos under icons/ are vendored from Devicon v2.16.0, retrieved from the pinned jsDelivr GitHub distribution:

https://cdn.jsdelivr.net/gh/devicons/devicon@v2.16.0/icons/
